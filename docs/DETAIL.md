# 侧栏标注（dsh-annotate）

在 DSH 右侧栏里打开的东西——网页、PDF、Markdown、纯文本、代码、图片——都能圈出来写批注，然后一键变成「裁好的图 + 带定位的编号提示词」放进输入框。

它解决的是长文档的老问题：你在一个 40 页的 PDF 第 12 页框了一段写「这里要改」，模型只看截图很难知道你说的是哪块。所以每一条批注都会带上**定位信息**——页码、行号、章节标题，以及框里那段原文——文字是最可靠的锚点，页码和行号只是辅助。

## 怎么用

1. 在右侧栏打开网页 / PDF / Markdown / txt / 代码 / 图片。
2. 右上角出现小按钮。网页上是「标注页面」，文件上是「标注文档」。点它。
   - **网页**：画面定格成一张真实的截图（滚动位置、缩放、暗色模式都是你看到的样子）。
   - **文档**：页面不冻结，你还能滚动，框会跟着内容走。
3. 直接拖出要标注的区域，卡片才会出现，并且**贴着你刚画的框**：优先在框的右边，右边放不下就换到左边，再不行就放到框的上/下方；位置按窗口大小夹住，不会跑到屏幕角落。点别的框，卡片跟着跳过去；拖新框时卡片暂时让开。卡片里实时显示这一框的定位（`第 12/40 页`、`第 140–152 行`、`小标题 · 框内文字…`）。
4. 点「插入输入框」，草稿里会出现裁剪图和编号说明。
5. 检查一下，照常发送。

## 定位是怎么算出来的

- **PDF**：框落在哪一页由 `[data-pdf-page]` 决定，页码直接取自 DSH 渲染的页容器；引文取自 pdf.js 的文本层（透明文字层）里与框相交的文本。附图从该页的 `<canvas>` 上按设备像素比裁下来（2× 屏就是 2 倍分辨率原图，不会糊）。
- **纯文本 / 代码**：每行都有 `[data-textpreview-line="N"]`，所以能给出精确行号区间 + 那几行的原文。
- **Markdown**：没有行号，取最近的标题 + 框内文字。
- **图片**：从预览里的 `<img>` 按原始分辨率裁（2× 图就是原图分辨率），没有文字锚点。
- **网页**：位置词（左上/居中…）+ 最近的标题 + 框内文字。元素路径只在内部保留，不会写进提示词——对模型来说，方位加原文比一层层 CSS 选择器更好用。

提示词末尾固定带一句：

> （定位以引号里的文字为准：页码/行号对不上时，请先按这段文字在文件里定位，再作答。）

这样即使文件被改过、页码漂移，模型也能靠原文找回位置。

## 提示词长什么样

```
我在「docs/guide.pdf」里标了 2 处，编号与附图一致（每张附图是对应区域的截图）：

1. 第 12/40 页 · 3.2 缓存失效策略 旧样式会被浏览器缓存… · 这一节的标题要改
2. 第 18 行 · const cache = new Map() · 这里应该限制容量

（定位以引号里的文字为准：页码/行号对不上时，请先按这段文字在文件里定位，再作答。）
```

纯文本/代码这类没有「画面颗粒」的内容不产生附图，只有文字定位和批注。

## 细节

- 悬浮按钮只在右侧栏里真的有内容、且宽度 ≥200px 时出现；400ms 跟随一次面板位置，拖动或缩放都跟得上。
- 刚点「标注」时画面上只有一行提示，没有遮挡；画出第一个框之后批注卡片才出现，并且放在面板外面，所以继续框选新区域不会被挡住。
- 卡片里只有编号和关闭按钮，没有多余的小字：选中某个框后，编号变蓝、框线变蓝，框右上角会出现一个 `✕` 用来删掉这一个框；卡片右上角的 `✕` 是关掉整个标注。
- 网页用 Electron `<webview>` 的 `capturePage()`，所见即所得；定格期间用 `visibility:hidden` 遮住网页，插入或 Esc 后自动恢复。
- 文档模式不遮页面：浮层是透明的，滚轮可以直接滚文档，框按内容坐标保存，滚动时跟着走。
- 需要先在左侧选一个会话；没选会话时会提示。
- 裁图按设备像素比：2× 屏裁出来的是 2 倍分辨率原图，不是把缩略图放大。
- 提示词里的定位是「给模型的线索」而不是「保证」：文件改过之后页码会漂，所以文案里明确说「以引号里的文字为准」。

## 边界

- 网页标注只对 Electron 桌面版的右侧栏浏览器有效（那里是真正的 `<webview>`）；浏览器里的 web 版右侧栏是沙箱 iframe，拿不到画面，按钮不会出现。文档标注不受这个限制。
- 网页定格后不能继续滚动或点击网页；要换位置就 Esc 退出，滚动后再点一次。
- PDF 只对已经渲染出来的页面有效：还没滚到的页没有 canvas，框不到；先把那页滚进视野。
- Word / PowerPoint 预览也是走 PDF 通道渲染的，所以页码、引文、裁图都能用（页码是这份「转换后 PDF」的页号）。
- Excel 预览是表格栅格，暂不产生裁图，只给批注和文件名。
- 不支持跨页面保存批注；一次用完即弃。
