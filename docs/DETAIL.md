# 侧栏标注（`@wuwen1994/dsh-annotate`）

在 DSH 右侧栏里打开的东西——网页、PDF、Markdown、纯文本、代码、图片——都能圈出来写批注，按回车变成「裁好的图 + 带定位的一行提示词」放进输入框；框会缩成一个气泡，点它可以回头改。

它解决的是长文档的老问题：你在一个 40 页的 PDF 第 12 页框了一段写「这里要改」，模型只看截图很难知道你说的是哪块。所以每一条批注都会带上**定位信息**——页码、行号、章节标题，以及框里那段原文——文字是最可靠的锚点，页码和行号只是辅助。

## 怎么用

1. 在右侧栏打开网页 / PDF / Markdown / txt / 代码 / 图片。
2. 面板顶部的工具栏里，刷新按钮右边多了一个标注图标（网页和文件都用同一个图标，悬停提示会写「标注页面」或「标注文档」）。点它。
   - **网页**：画面定格成一张真实的截图（滚动位置、缩放、暗色模式都是你看到的样子）。
   - **文档**：页面不冻结，你还能滚动，框会跟着内容走。
3. 直接拖出要标注的区域，卡片才会出现，并且**贴着你刚画的框**：优先在框的右边，右边放不下就换到左边，再不行就放到框的上/下方；位置按窗口大小夹住，不会跑到屏幕角落。点别的框，卡片跟着跳过去；拖新框时卡片暂时让开。定位信息（`第 12/40 页`、`第 140–152 行`、`小标题 · 框内文字…`）只记在后台、写进提示词，卡片上不显示。
4. 写批注，按 `Enter`：这块区域连同批注变成输入框里的一行，画面上的框缩成一个蓝色玻璃气泡（里面有它的编号），标注**不退出**——接着框下一处、写下一句、再按 `Enter`。`Shift+Enter` 在批注里换行。
5. 想改某一条：点它的气泡，卡片重新打开（框会在原位置高亮），改完 `Enter` 就把草稿里那一行改掉；不想要了就点卡片右上角 ✕：这条气泡连同输入框里那一行、以及它贴进去的裁图一起删除，其余自动补位。
6. 全部写完后检查输入框里的若干行和附图，照常发送；这批提示词发出去之后气泡自动消失。

## 定位是怎么算出来的

- **PDF**：框落在哪一页由 `[data-pdf-page]` 决定，页码直接取自 DSH 渲染的页容器；引文取自 pdf.js 的文本层（透明文字层）里与框相交的文本。附图从该页的 `<canvas>` 上按设备像素比裁下来（2× 屏就是 2 倍分辨率原图，不会糊）。
- **纯文本 / 代码**：每行都有 `[data-textpreview-line="N"]`，所以能给出精确行号区间 + 那几行的原文。
- **Markdown**：没有行号，取最近的标题 + 框内文字。
- **图片**：从预览里的 `<img>` 按原始分辨率裁（2× 图就是原图分辨率），没有文字锚点。
- **网页**：位置词（左上/居中…）+ 最近的标题 + 框内文字。元素路径只在内部保留，不会写进提示词——对模型来说，方位加原文比一层层 CSS 选择器更好用。

每一行都是独立的，只写「编号 + 位置 + 框内文字 + 你的批注」，没有整段的前缀和后缀——段落和编号本身就说明了顺序。

## 提示词长什么样

```
1. docs/guide.pdf · 第 12/40 页 · 3.2 缓存失效策略 旧样式会被浏览器缓存… · 这一节的标题要改
2. docs/guide.pdf · 第 18 行 · const cache = new Map() · 这里应该限制容量
```

纯文本/代码这类没有「画面颗粒」的内容不产生附图，只有文字定位和批注。

## 细节

- 触发图标是往面板自带工具栏里插一个占位 `<span>`、再 `createPortal` 进去的：右侧栏没有「扩展工具按钮」的槽位，这是唯一能紧挨刷新按钮的办法；找不到工具栏时退回右上角的浮动图标。400ms 同步一次。
- 点图标之后画面上没有任何提示条（不再挡住要框的地方）；画出第一个框之后批注卡片才出现，并且贴着框放在面板外面。
- 卡片里只有关闭按钮，没有编号栏、没有插入按钮、没有必要的小字；框上也没有任何按钮。选中某个框后框线变蓝，按 `Delete` 删掉这一个框；已插入的条目用气泡卡片的 `✕` 删（提示词里那一行和它的裁图一并删掉）；右键点画面则退出整个标注。
- 回车插入的是**当前选中的框**（没选中就是最后画的那个），一次一条，标注不会退出；编号按存活条目算，删掉中间一条后面的会自动补位，退出标注重新开始又从 1 数起。
- 插入过的条目变成气泡浮在画面原位置；文档模式滚动时气泡跟着内容走。气泡靠比对草稿文本来判断去留：那一行从输入框里消失（发出去了或被手动删掉）气泡就收起。
- 网页用 Electron `<webview>` 的 `capturePage()`，所见即所得；定格期间用 `visibility:hidden` 遮住网页，插入或 Esc 后自动恢复。
- 文档模式不遮页面：浮层是透明的，滚轮可以直接滚文档，框按内容坐标保存，滚动时跟着走。
- 按住回车只会插入一次（keydown 会自动重复）；批注里用 `Shift+Enter` 打的换行在插入时折成空格，保证每条提示词就是一行——气泡靠整行文本找回自己，换行会让它找不到。
- 标注途中侧栏切走标签页或被关掉，标注会自动收尾、恢复页面显示；未插入的框丢弃，已插入的气泡保留。
- 需要先在左侧选一个会话；没选会话时会提示。
- 裁图按设备像素比：2× 屏裁出来的是 2 倍分辨率原图，不是把缩略图放大。
- 提示词里的定位是「给模型的线索」而不是「保证」：文件改过之后页码会漂，所以每一行都带上文件路径和框内原文，方便模型自己回去核对。

## 边界

- 网页标注只对 Electron 桌面版的右侧栏浏览器有效（那里是真正的 `<webview>`）；浏览器里的 web 版右侧栏是沙箱 iframe，拿不到画面，按钮不会出现。文档标注不受这个限制。
- 网页定格后不能继续滚动或点击网页；要换位置就 Esc 退出，滚动后再点一次。
- PDF 只对已经渲染出来的页面有效：还没滚到的页没有 canvas，框不到；先把那页滚进视野。
- Word / PowerPoint 预览也是走 PDF 通道渲染的，所以页码、引文、裁图都能用（页码是这份「转换后 PDF」的页号）。
- Excel 预览是表格栅格，暂不产生裁图，只给批注和文件名。
- 不支持跨页面保存批注；一次用完即弃。
