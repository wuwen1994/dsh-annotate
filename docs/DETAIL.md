# 侧栏标注（`@wuwen1994/dsh-annotate`）

在 DSH 右侧栏里打开的东西——网页、PDF、Markdown、纯文本、代码、图片、Excel——都能圈出来写批注，按回车变成「裁好的图 + 带定位的一行提示词」放进输入框；框会缩成一个气泡，点它可以回头改。只想说一句话的时候，也可以直接划出那句原文、右键选「批注」，写一句就进输入框，不用框、不带图。

它解决的是长文档的老问题：你在一个 40 页的 PDF 第 12 页框了一段写「这里要改」，模型只看截图很难知道你说的是哪块。所以每一条批注都会带上**定位信息**——页码、行号、单元格范围、章节标题，以及框里那段原文——文字是最可靠的锚点，页码和行号只是辅助。

## 怎么用

1. 在右侧栏打开网页 / PDF / Markdown / txt / 代码 / 图片 / Excel。
2. 面板顶部的工具栏里，刷新按钮右边多了一个标注图标（网页和文件都用同一个图标，悬停提示会写「标注页面」或「标注文档」）。点它，或者按 `Alt+A`。
   - **网页**：画面定格成一张真实的截图（滚动位置、缩放、暗色模式都是你看到的样子）。
   - **文档**：页面不冻结，你还能滚动，框会跟着内容走。
   - 第一次进入时，画面左下角有一句 3 秒的提示，告诉你「拖一个框、写一句、回车」。
3. 直接拖出要标注的区域，卡片才会出现，并且**贴着你刚画的框**：优先在框的右边，右边放不下就换到左边，再不行就放到框的上/下方；位置按窗口大小夹住，不会跑到屏幕角落。点别的框，卡片跟着跳过去；拖新框时卡片暂时让开。定位信息（`第 12/40 页`、`第 140–152 行`、`Sheet1!B2:D14`、`小标题 · 框内文字…`）只记在后台、写进提示词，卡片上不显示。
4. 写批注，按 `Enter`：这块区域连同批注变成输入框里的一行，画面上的框缩成一个蓝色玻璃气泡（里面有它的编号），标注**不退出**——接着框下一处、写下一句、再按 `Enter`。`Shift+Enter` 在批注里换行。框多于一个时，标尺栏上有「全部插入 · N」，一次把剩下的框都插进去。
5. 想改某一条：点它的气泡，卡片重新打开（框会在原位置高亮），改完 `Enter` 就把草稿里那一行改掉；不想要了就点卡片右上角 ✕：这条气泡连同输入框里那一行、以及它贴进去的裁图一起删除。编号按这一批已经画出的框递增（取最大值 +1），删掉中间一条不会让后面的重排；下一批重新从 1 开始。
6. 全部写完后检查输入框里的若干行和附图，照常发送。这批提示词发出去之后气泡就全部消失，不留灰色的历史记录，也没有「上一轮」可以翻——想再标注就重新拉框，编号从 1 开始。

## 只批注一句话

框选描述的是「这一块」，一句话的疑问更适合直接划词：

1. 在 PDF / Markdown / txt / 代码 / 网页预览里划出要说的那句话（PDF 的文字层是可选的）。
2. 在选区上右键。预览里的右键菜单被插件接管了：有选区时是「复制 / 批注」，没有选区时仍然是系统菜单（输入框上右键也是系统菜单）。「复制」复制你划中的那几个字，和原来一样。
3. 点「批注」，选区旁边弹出批注卡片，顶部是这句话的预览（超出两行会截断，鼠标悬停看全文）。
4. 写一句想说的，`Enter` 发送，`Shift+Enter` 换行，`Esc` 放弃。回车后这行话进输入框，光标跟着过去。

网页里的划词由插件注入的一小段脚本接管：它在页面内拦住 `contextmenu`、把选区和坐标回报宿主，宿主再弹 DSH 自己的菜单。页面跳转后脚本会重新注入。

选区批注**不截图、不编号、不产生气泡**——它不占画面，不要了就删输入框里那一行。定位仍然是「文件路径 · 页码/行号 · 「选中的原文」 · 你的批注」，只是引号里只放你划中的那句话，不是整段：

```
docs/guide.pdf · 第 12/40 页 · 「浏览器会缓存旧样式」 · 这里和正文的矛盾要说清楚
notes/a.md · 第 140 行 · 「缓存失效以后，页面还在用旧样式。」 · 这句解释得太含糊
```

## 元素拾取（网页）

按住 `Shift` 点工具栏图标，进入拾取模式：鼠标划过段落、列表项、表格单元、标题时会高亮，单击就把那个元素变成一个框（仍然按矩形裁图），不用手画。`Esc` 退出。

## 定位是怎么算出来的

- **PDF**：框落在哪一页由 `[data-pdf-page]` 决定，页码直接取自 DSH 渲染的页容器；引文取自 pdf.js 的文本层（透明文字层）里与框相交的文本。附图从该页的 `<canvas>` 上按设备像素比裁下来。
- **纯文本 / 代码**：每行都有 `[data-textpreview-line="N"]`，所以能给出精确行号区间 + 那几行的原文。
- **Markdown**：没有行号，取最近的标题 + 框内文字。
- **图片**：从预览里的 `<img>` 按原始分辨率裁，没有文字锚点。
- **Excel / 表格预览**：优先按单元格的 `aria-rowindex` / `aria-colindex` / `data-row` / `data-col` 推范围，只有 HTML 表格自带的行列信息时用 `rowIndex` / `cellIndex`（第一行是 0，会折成 1），写成 `Sheet1!B2:D14`；框只覆盖一个格时写 `Sheet1!B2`。裁图取与框重叠面积最大的 `<canvas>`。推不出行列时退回文件名 + 框内文字。
- **网页**：位置词（左上/居中…）+ 最近的标题 + 框内文字。元素路径只在内部保留，不会写进提示词——对模型来说，方位加原文比一层层 CSS 选择器更好用。

每一行都是独立的，只写「编号 + 位置 + 框内文字 + 你的批注」，没有整段的前缀和后缀——段落和编号本身就说明了顺序。同一份文件一轮里插到 3 条以上时，会在这一组前面加一行 `[批注 · 文件路径]`，让模型知道下面几条是一组。

## 提示词长什么样

```
1. docs/guide.pdf · 第 12/40 页 · 3.2 缓存失效策略 旧样式会被浏览器缓存… · 这一节的标题要改
2. docs/guide.pdf · 第 18 行 · const cache = new Map() · 这里应该限制容量
3. budget.xlsx · Sheet1!B2:D14 · 这一行的合计口径不对
```

纯文本/代码这类没有「画面颗粒」的内容不产生附图，只有文字定位和批注。

## 细节

- 触发图标是往面板自带工具栏里插一个占位 `<span>`、再 `createPortal` 进去的：右侧栏没有「扩展工具按钮」的槽位，这是唯一能紧挨刷新按钮的办法；找不到工具栏时退回右上角的浮动图标。同步靠 `MutationObserver`（60ms 合并），观察不到时退回 400ms 轮询，另有一层 2 秒兜底。
- 点图标之后画面上没有提示条（第一次进入时那句 3 秒提示除外）；画出第一个框之后批注卡片才出现，并且贴着框放在面板外面。
- 卡片里只有关闭按钮，没有编号栏、没有插入按钮、没有必要的小字；框上也没有任何按钮。选中某个框后框线变蓝，按 `Delete` 删掉这一个框；已插入的条目用气泡卡片的 `✕` 删（提示词里那一行和它的裁图一并删掉）；右键点画面则退出整个标注。
- 回车插入的是**当前选中的框**（没选中就是最后画的那个），一次一条，标注不会退出；编号按这一批已经画出的框递增（取最大值 +1），删掉中间的框不会让后面的重排，发送之后整批归零、下一次拉框从 1 开始。
- 插入过的条目变成气泡浮在画面原位置；文档模式滚动时气泡跟着内容走。气泡与草稿行的对账不再依赖整行文本：行首编号 + 引文片段 / 路径 / 批注片段任一命中就认作同一条，改个标点或补个词都不会让气泡消失。
- 气泡只代表草稿里还在的那一行：发送时整批一起消失，草稿被清空也一起消失，手删某一行只掉那一条（缩略图一并回收）。不保存历史、不做账本、不写 localStorage，下一批从 1 重新编号。
- 气泡只跟着它自己那一页：同一个浏览器面板里换标签、同一个文件预览里换文件都算换页，旧页的气泡不会叠到新页面上，切回来还能点。
- 网页用 Electron `<webview>` 的 `capturePage()`，所见即所得；定格期间用 `visibility:hidden` 遮住网页，插入或 Esc 后自动恢复。
- `Alt+A` 在网页里也有效：光标在网页正文时按键只到页面自己的 document，宿主窗口收不到；注入的脚本在页面里接住 `Alt+A`（输入框/可编辑区域除外），通过 console 通道回报宿主，再走与工具栏图标相同的开启/关闭逻辑。
- 文档模式不遮页面：浮层是透明的，滚轮可以直接滚文档，框按内容坐标保存，滚动时跟着走。
- 按住回车只会插入一次（keydown 会自动重复）；批注里用 `Shift+Enter` 打的换行在插入时折成空格，保证每条提示词就是一行。
- 标注途中侧栏切走标签页或被关掉，标注会自动收尾、恢复页面显示；未插入的框丢弃，已插入的气泡保留到这批结束。
- 需要先在左侧选一个会话；没选会话时会提示，提示旁边有「去选会话」这类动作按钮，不用自己找。
- 裁图统一走 JPEG：长边超过 1568px 先等比缩到 1568，再以 q0.9 编码；框的四周各外扩 8px，避免正好切在字腰上。鼠标停在气泡上可以看到那张裁图的缩略图。
- PDF 的文字层还没渲染出来时（框在页面刚滚进视野的时候），插入会先等最多 2 秒等 canvas 出现；仍然没有就只写文字定位，并在卡片上给「裁图缺失 · 重试」按钮。重试用的是点下去那一刻的框，不是报错那一刻的。
- 文件在批注期间被改过的时候不会主动校验：定位信息里的文件路径和框内原文就是你回去核对时的线索。
- 划词批注走的是 DSH 的 `contextMenus` 服务：插件在 document 的捕获阶段接住 `contextmenu`，选区确实落在预览正文里就 `preventDefault()`——Electron 的原生右键菜单在主进程里拼装，插件没法往里加项，只有取消默认行为才能换成自己的菜单。菜单本身是 DSH 的 Web 弹层，不是插件自绘的。
- 选区批注用同一套锚点读取（页码 / 行号 / 最近标题），只是把「框内文字」换成「选中的文字」；发送时 `files: []`，不建附件。
- 提示词里的定位是「给模型的线索」而不是「保证」：文件改过之后页码会漂，所以每一行都带上文件路径和框内原文，方便模型自己回去核对。

## 边界

- 网页标注只对 Electron 桌面版的右侧栏浏览器有效（那里是真正的 `<webview>`）；浏览器里的 web 版右侧栏是沙箱 iframe，拿不到画面，按钮不会出现。文档标注不受这个限制。
- 网页定格后不能继续滚动或点击网页；要换位置就 Esc 退出，滚动后再点一次。元素拾取也只在定格后的网页上生效。
- PDF 只对已经渲染出来的页面有效：还没滚到的页没有 canvas，框不到；滚过去再框，或者用「重试」补裁图。
- Word / PowerPoint 预览也是走 PDF 通道渲染的，所以页码、引文、裁图都能用（页码是这份「转换后 PDF」的页号）。
- Excel 预览的单元格锚点依赖预览 DOM 暴露的行列信息；暴露不全时只给文件名和框内文字，但仍尽量裁图。
- 不保存任何历史：没有账本、不写 localStorage、不落项目文件；这一批的气泡在发送、清空草稿或换会话时就没了，下一批重新从 1 编号。
- 划词批注在网页里也生效了（注入脚本），但选区超过 4000 字会截断；框选的引文最多 180 字，划词的引文最多 400 字。
